# Keyword Protection Rule

Never shrink the keyword pool aggressively as a side effect of routine optimization.

A high ACOS keyword is not automatically a bad keyword.

Before pausing, deleting, or negatively targeting, assess:
- clicks and spend
- CPC and CTR
- CVR and orders
- sales and historical performance
- search-term relevance
- match type
- campaign role
- exploration value
- recent versus longer-term trend

Preferred sequence when evidence is incomplete:
1. observe
2. reduce bid if appropriate
3. constrain budget if appropriate
4. test a different match/placement structure
5. use a negative or pause only with stronger evidence
