# PPC Test Fixtures

Anonymous, synthetic fixtures only. Never place real Amazon Ads exports, customer data, credentials, or account identifiers in this directory.

The fixtures are designed to test:

- converting search-term harvesting
- promising but under-sampled testing
- high-ACOS exploratory terms that should be protected
- clear irrelevant/wasteful terms eligible for suppression review
- conservative bid recommendations
- discovery-capacity preservation

Fixtures are inputs for Dry Run and regression checks. They are not production account data.
